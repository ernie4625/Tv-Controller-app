# Brand logos

White-on-transparent PNGs (96 px tall, cropped to the artwork) used on shortcut tiles and tinted at runtime.

- **Source:** [simple-icons](https://simpleicons.org) v16.32.0. The artwork files are CC0.
- **Trademarks:** every logo belongs to its owner. Real logos are shown by ED's choice during development. Review them before the App Store submission at M7 (Apple guideline 5.2).
- **Not in simple-icons:** Prime Video, Hulu, Disney+, Peacock, Pluto TV, ESPN and NFL. These use styled wordmarks (see `src/catalog/shortcuts.ts`) until official files are added here.
- **Adding a logo:** drop a white-on-transparent PNG named `<shortcut id>.png` here and add it to `src/catalog/logos.ts` with its width ÷ height ratio.
